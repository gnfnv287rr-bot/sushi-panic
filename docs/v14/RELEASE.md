自动休息仍为20秒：饱腹、精神、分数、出盘与保底冻结。传送带采用单独的展示偏移，休息时以约30fps低速绘制，不生成可吃的新盘或积分；点现有盘自动恢复，手动暂停/查看菜单仍尊重原操作。隐藏停止RAF及声音，恢复重置单调时钟，不补跑后台时间。自然休息与切后台不弹阻断窗口。

存档v2沿用原journal命名空间，保存版本、规则/菜单版本、服务端种子、好友快照、合法事件/活动ticks与展示偏移。角色、精神、饱腹、积分、图鉴及保底由原种子/事件重建，不相信本地改分；所有旧版引擎继续独立验证。回到门口不会被强拉回，重开页面才自动续桌。网络失败保留本局和重试；断网练习有独立本地记录，绝不冒充云端成绩。

Web Locks确保同一未结账对局只有一个窗口续写；不支持时使用低频续期的本地租约，失去所有权不能抢写。游戏暂停期间不重复写存档，每5秒检查只写变化，吃盘/休息/退出时及时保存。对象与音效队列有界，无后台补帧或无用计分计时器。

BGM新玩家默认开、低音量，已有明确关闭/静音保留。有浏览器允许的自动播放策略时尝试，否则首个真实手势启动；不绕过限制。前台安全休息音乐可以继续，后台暂停；沿用原独立音量、静音和分类音效。
