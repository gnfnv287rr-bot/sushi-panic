# 已知问题与优化方向

v0.2.0 / 2026-10-19。当前未发现阻断首局的自动化失败；下列未验证项和体验问题仍需处理。

| 优先级 | 问题 / 已有证据 | 当前影响 | 后续处理 |
| --- | --- | --- | --- |
| P1 | 尚无正式组织的真人测试（已有用户自然试玩反馈） | 不能判断难度、操作舒适度、紧张感或重玩意愿 | 首轮 5–8 人，每人至少 3 局，记录理解时间、死因、误触、是否自发再来一局；这是计划，不是既有数据 |
| P1 | 无 iOS Safari / Android 真机测试 | 触摸、地址栏伸缩、音频、电耗与性能仅有 Chromium 模拟保障 | 真机验证后决定兼容性修复，不能宣称移动端全面验收 |
| P1 | 谨慎模拟 1000/1000 存活 5 分钟且未掉血 | 有供给可解的证据，同时提示熟练后可能缺少压力 | 先观察真人；后期事件、限时模式和局部抓取区均需主策划确认 |
| P2 | 同策略角色均分仍相差约 17.7% | 抽到的角色仍影响冲纪录效率，共享榜仍仅为娱乐排行，未完成角色竞技平衡 | 先测真实角色难度，提议角色分榜 / 同种子同角色挑战；不擅自取消随机角色 |
| P2 | 320px 窄屏盘签字体较小、转角可能视觉拥挤 | 自动命中与范围测试通过，但阅读与大拇指遮挡未验证 | 真机观察后调整标注优先级或按住查看；不要隐藏过敏信息 |
| P2 | 横屏矮视口允许页面滚动 | 布局不横向溢出，但不保证仪表和全场同屏 | 移动首版优先竖屏；后续做专门横屏布局 |
| P2 | 第九盘之后没有数字快捷键 | 鼠标/触屏可抓所有盘子，键盘最多对应前八盘 | 真人键盘反馈后决定循环选择方式；当前说明已明确 |
| P2 | 离线单文件存储策略由浏览器决定 | file://、隐私模式或禁止存储下，最高分可能不持久；游戏继续运行 | 网页/局域网方式更稳定；已实现拒绝存储时降级 |
| P2 | 基础服务器复算已实施，但客户端与自动玩家仍可构造合法日志 | 能阻止直接伪造积分，不等于专业反作弊 | 后续补反滥用、长期重放容量与运行观测 |
| P3 | 仍有 Canvas 视觉玩法的可访问性缺口 | 有键盘、语义 HUD、原生弹窗，但读屏用户无法完整辨认每个动态盘子 | 独立规划低动态/列表玩法，明确测试人群后实现 |
| P3 | 资源为原创程序插画、音效为合成短音 | 完成玩法表达，尚未做完整动画、音乐和品牌美术迭代 | 在真人核心循环验证后投入精修 |

已修复问题：浮点整数分丢失；轨道描边污染盘子；开局命中数据滞后；手机 HUD 与整条轨道不能同屏；入口密集补盘和出餐欠账。对应决策与回归证据见 DECISIONS.md / TEST_REPORT.md。

未实现且需确认的重大方向：限时/任务制模式、只允许前轨抓取、角色自选/主动技能、局外成长、广告和付费。它们不是默认后续承诺，不应在未确认时改变当前生存玩法。


## v0.2.0 联网限制

- **P1 地区网络**：中国朋友此前被 chatgpt.site 的 Cloudflare 拦截。Pages 页面独立托管，但共享 API 仍在该域名；接口不可达会明确进入练习局，无法计入共享榜。尚未由朋友原网络复测。
- **P2 身份恢复**：ID 绑定当前域名/浏览器的本地凭证。换设备、从 Pages 切到 Sites 或清空存储后，仅输入同一 ID 不能取回成绩。当前无账号找回，不应把 ID 当密码。
- **P2 服务容量**：只实现按凭证限流与输入边界，未做持续压力测试；合法长局同步重放在 Worker 的 CPU 预算下仍需测量。没有专业机器人检测或全局反滥用。
- **P2 数据保留**：公开显示 ID 和最佳战绩；验证局记录暂未自动清理。产品化需明确数据保留/删除流程。
- **P2 离线补交**：只有开局时已创建的联网局能补交，最多保存 3 局、7 天有效；纯练习局和旧本机纪录不会补进共享榜。

已完成：玩家自填 ID 替换随机姓名、服务端种子与复算、个人最佳积分和唯一榜首称号、跨访客共享、断网明确练习、空榜真实显示和长 ID 换行。
