# 《寿司别吃撑！》游戏设计

版本：v0.2.0；2026-10-19。状态：可玩原型及共享积分榜；核心数值沿用 v0.1.0。

## 定位与循环

独立超休闲、回转寿司主题、单局生存。玩家点击移动的盘子，吃寿司补充持续减少的饱腹，避免饥饿、过饱和误食过敏源。目标是活得更久、做出更好的选择，死亡后快速重开。首版保留无尽生存定位，不加入经营、合成、养成或付费能力。

流程：输入玩家 ID → 随机体质卡（时间停止）→ 确认入座 → 点击进食 / 等待消化 → 难度递增 → 生命归零 → 结账单 → 新角色卡 → 再次开吃。暂停、帮助和离开窗口时冻结整个对局。

输入：主指针点击/触摸盘子；数字键 1–8 对应当前盘旁编号，最多显示前八个。P / Esc 暂停、继续。每次成功进食间隔至少 0.24 秒，右键、非主触点和键盘长按重复事件不触发进食。重开只需结算页一次点击、确认新角色一次点击，没有广告或额外等待。

| --- | ---: | ---: | ---: | --- | --- |
| 桃桃 · 杂食小行家 | 100 | 3.6 | 1.00 | 虾类 | 前后两份安全寿司品种不同，回 1 生命；第一份不触发 |
| 阿太 · 快饿大胃王 | 110 | 4.3 | 0.85 | 鱼子 | 基础食物分 ×1.15；更快饿、同份食物更不顶饱 |

所有回血均不超过最大生命。这些是游戏设定，不表达真实过敏或营养医学判断。

## 随机与出餐

1. 每袋包含 8 类各一份，用带种子的 Fisher–Yates 洗牌后逐个取出，空袋重新洗。
2. 最多连续两份非通用安全正饱腹食物。若将超过，注入一份黄瓜卷；注入不消耗袋内食品。因此最终分布不是八类等概率，黄瓜卷占比更高。
3. 开局即时放 4 盘，含一份黄瓜卷和一份饭团；另外两份来自随机袋。所有盘子从第一帧即可点击。
4. 出餐间隔随难度变化；入口与出口接缝附近存在盘子时等待净空，场上最多 14 盘。不积累延迟出餐欠账，防止突然成团出现。
5. 全部轨道都可抓取，盘子到末端撤走，持续补新盘。不限制在单个“抓取窗口”。

保底保证出餐序列，不保证玩家已经误食、多次喝茶或主动不吃之后还能被救回。详见测试报告对“无解”的有限结论。

## 难度曲线

设 `q = min(t/180,1)`，t 为实际对局秒数，暂停时间不计。

```text
等级         = min(6, 1 + floor(t/25))
饱腹消耗/秒  = 角色基础消化 × (1 + 0.65q)
传送带圈数/秒= 0.044 + 0.026q
目标出餐间隔 = 1.85 − 0.70q 秒（可能因入口净空顺延）
```

125 秒进入 6 级后数值仍平滑增长，180 秒全部封顶。最高消化倍率 1.65，传送带约 14.29 秒一圈，目标出餐间隔 1.15 秒。用相同的“圈数/秒”保持不同屏幕的时间机会相近；实际指向难度仍须真机验证。

## 得分

- 舒适区生存每秒 12 分，其他区域每秒 8 分。随时间积分，最后显示整数。
- 安全正食物给基础食物分；吃完仍处于 25–85 则连击 +1，额外 `30 + 8×min(连击,10)` 分。否则连击归零。
- 每种安全正食物首次吃到额外 25 分。过敏食物不计安全品种。
- 茶给基础 20 分，不累加或清空连击；不触发舒适/品种奖励。
- 阿太基础食物分再乘 1.15；茶不享受该加成。
- 为校正快消化角色天然吃得更多，所有食物分与进食奖励乘 `K = 角色份量系数 ×3.6 /角色基础消化`。生存分不乘 K。
- 总分取 `floor(生存分 + 食物分 + 进食奖励 + 1e−8)`，极小补偿仅用于消除浮点落在整数下方的误差。

K：桃桃 1，阿太约 0.7116，柚子 1.38，小海约 0.9474。角色天赋和可吃食物差异仍会影响成绩；v0.2.0 增加娱乐性质的共享积分榜，角色差异仍然存在。当前同策略模拟均分仍相差约 18%，不能宣称角色完全等强。

## 反馈与表现

枫木色台面、绿色链板、珊瑚红警示、原创猫厨师与寿司程序插画。正负饱腹、食品名称、红色“忌”同时展示，避免仅靠颜色辨认危险。危险状态显示宽限倒计时与生命流失提醒；成功进食给浮字、粒子、连击和可关闭音效。保持原生按钮焦点和仪表语义。

## 版本边界

本版已经实现用户要求的全部 MVP 系统。真人难度、长期留存、手感和动机未验证。限时模式、只允许前轨抓取、角色自选、主动技能、强化道具等均未实装；涉及核心循环的建议记录在 KNOWN_ISSUES.md，等待主策划确认。

## v0.1.1 表现修订

仅增强状态辨识：加粗生命/饱腹条、放大数字、显示生命上限、饱腹实心填充与醒目指针，按舒适/偏离/危险显示绿/琥珀/红色。饥饿、过饱、低生命在场景中央补充动作提示与危险倒计时；提示不接收指针事件。窄屏保留仪表和全轨同屏。本文所有规则与数值继续作为当前版本基线，没有平衡改动。

## v0.1.2 提前预警

当饱腹低于 25 或超过 85、尚未进入真正危险区时，在场景中央显示琥珀色行动提示。进入 <15 / >100 的危险区后升级红色，并沿用原来的掉血倒计时。实际危险与低生命优先显示；恢复舒适且无低生命时提示消失。提醒只提供信息，不暂停时间、不阻挡点盘，不改变既有舒适奖励与伤害规则。


## v0.2.0 玩家 ID 与共享积分榜

用户确认排行榜按「积分」排序。玩家在首页输入 ID，替代随机姓名；每局继续随机体质、过敏源和被动能力。原角色数据表中的名字仅是历史内部代号，界面显示玩家 ID 和体质名称。

- 每个玩家凭证只保留一份最佳成绩，按单局最高总积分降序，榜首获得「大胃王」。显示前 50 名，同时可查询自己在全榜的名次。
- 同分依次比较该最佳局的寿司盘数、生存时长、成绩提交时间（较早优先）；最后用稳定内部键打破完全相同的顺序，因此榜首只有一名。
- 结算附带寿司盘数；乌龙茶不计寿司，但原有茶的积分规则不变。不是累计吃盘榜或累计刷局积分。
- 仅服务端创建、正常结束、复算通过的联网计分局上榜。不能把客户端填写的分数或旧本机纪录直接上传。
- 离线或接口连接失败时明确标注练习局，不伪造共享榜单；榜单无成绩时显示空态，不插入演示玩家。
- ID 2–16 字符，规范化后校验；英文大小写视为同名。ID 与当前链接、浏览器保存的随机凭证绑定，不是跨设备登录账号。

本次不改动进食得分、伤害、角色强度、随机供给与生存目标。角色分榜、每日同种子挑战仍为待主策划确认建议。
