# V1.2.3 · 清新寿司小店

## 设计依据与取舍

Owner 提供两张参考：P1 是蓝色、饱满、圆润的中文标题；P2 是白底、蓝字和明亮食材色。此前米色纸底、灰绿传送带和毛笔菜单标题偏灰、偏传统。本次只调整呈现，不改菜单、概率、积分、角色、云端数据和规则版本。

配色：清白底 #f6fbff / 纯白卡片 #ffffff；深海蓝正文 #195584；晴空蓝标题 #2484df；薄荷绿 #74b29b 传送带；番茄橙 #ff8c64 主按钮；玉米黄 #fff0cd 台面。危险红与舒适绿仍有明确语义。主按钮使用深棕字，以保证明亮橙底上的阅读对比度。

字体：欢迎语与菜单/图鉴/排行榜标题用圆润字体子集，正文用系统中文无衬线，数字用等宽。先试快乐体，截图检查后发现笔画偏尖，改用寒蝉全圆体；制作子集并改内部名称，随包保留作者 OFL。来源与复现见 assets/fonts/README.md。

保留原传送带插画和动线，统一调整帘子、台面、轨道、表单、导航、弹窗及图鉴的颜色；不引入照片和额外装饰，以免改变现有插画风格。欢迎语精确改为「欢迎光临，今天想吃点什么？」。手机上分两行，最高纪录另起一行，避免拥挤。
