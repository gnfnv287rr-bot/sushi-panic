# V1.2.2 · 让收藏看得见

## 审查与取舍

已检查index.html、main/social/identity/storage、图鉴记录、主题配置、Renderer和现有移动布局。开始时Git干净，线上1.2.1与Actions一致。222种可收藏、216款当期菜＋茶的数量口径保留；不改种子、概率、计分或数据库，不需要数据迁移。

沿用纸色#f9f5eb、海苔墨#293f40、抹茶#4e7970、珊瑚#df6853，加一笔奖牌金#c39a45。功能字用系统中文无衬线，分数用等宽；仅「今日放题／我的寿司手帐／今日大胃王」用OFL手写字体子集。页面仍以原传送带为中心，不另做大型首页。

排布比较：全入口同一排在390px会挤成小字；侧边抽屉又藏住核心功能。因此桌面分主要/辅助组，手机3×2明确标签，游戏中压缩品牌留给画面。传送带下是手帐式收藏横条，避免再叠大型卡片。新品反馈在轨道内圈的空白处，不覆盖盘子，pointer-events:none，排队约2.1秒；只在真实吃到新品时触发。

## 数据语义

进度展示云端已确认＋本机待核验的并集，并分别标数量；总数和主题数量从目录动态算，重复菜不增种数。练习发现明确标本机，不冒充云端。同步中／失败／等待／游客云端／绑定后同步分别处理；邮箱已绑定不代表本局写入成功。

NEW、已查看和温和提醒只保存当前浏览器、按玩家UUID分隔；已有远端收藏读入不重播动画。跨设备图鉴及品尝次数仍来自原云端，但NEW已读标记不跨设备同步。本版避免为呈现偏好迁移数据库。查看卡片在图鉴可见至少700ms后消去NEW，离开视口不算查看。

提醒为非模态内嵌文案：未绑定且档案已识别后出现，用户关闭后至少7天不再显示；满10种后才可再次温和出现，已绑定不显示。没有新注册要求或自动发送邮件。

## 字体核查

[Ma Shan Zheng官方OFL](https://github.com/google/fonts/blob/main/ofl/mashanzheng/OFL.txt)允许按OFL分发/嵌入；保留版权和许可文件。源字体约5.6MB，仅截取标题字生成9.3KB WOFF2，同站托管、离线版内嵌；不依赖Google字体CDN。下载API截断后改用同一官方仓库raw地址完整文件，未转用来源不明字体。

百分比保留一位小数，避免首口1/222被整数舍入成0%而没有进度条增长；已发现/确认数量仍按整数去重。
