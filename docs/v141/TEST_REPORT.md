## 限制

- Chrome尺寸/触屏模拟不等于iPhone/Android真机与Safari测试；本次未在中国多网络实测。
- 游客身份清理浏览器数据后仍需此前绑定邮箱才能恢复；匿名身份不会凭昵称恢复。练习口味只在本机。
- 网络失败保留本机待传，不承诺立刻云端成功；多设备同时编辑冲突需采用云端或明确再保存，防止旧值静默覆盖。
- 服务器验证合法事件/节奏，不证明点击来自真人；原6小时活动tick/25,000动作上限继续存在，休息不消耗活动预算。
- 无新音乐/第三方图形资源，无新依赖、付费服务或经济/任务系统。
