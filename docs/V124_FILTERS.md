# V1.2.4 · 图鉴分类栏

Owner要求以参考P2的横向筛选栏取代图鉴里的大下拉框，统一标题分类名称。复用V1.2.3的清白/蓝/薄荷配色、圆润标题与系统正文字。仅选中项用浅蓝底，分类标签左对齐；菜单、等级、排序分别独立一行，搜索与重置在最后一行。没有再套一层大卡片或给整行染色。

## 命名与行为

- 菜单分类：全部／本期菜单／常驻菜单／往期菜单。收藏进度沿用同一组名称；悬停提示保留原主题全名。仅在显示层映射，主题ID、目录与历史收藏不变。
- 珍稀等级：全部／日常／精选／珍藏。原先菜单下拉里的“珍藏寿司”与等级重复，统一由珍藏筛选覆盖，旧隐藏收藏仍可在这里看到。
- 排列顺序：最近发现／图鉴编号。修正原编号排序仍把已发现寿司挪到前面的不一致，编号顺序现在按编号升序；最近发现保留已发现优先及最近时间排序。乌龙茶不在图鉴，编号不必连续。
- 搜索寿司：菜名或图鉴编号。与分类、等级组合过滤；变更条件自动回第一页。
- 重置筛选：一键恢复全部菜单、全部等级、最近发现、空搜索及第一页。没有结果时显示明确提示，不伪造收藏卡片。
- 收藏与珍稀说明：默认折叠，保留原概率与保底说明。实际同步状态继续常显。

按钮组带组名称与aria-pressed，支持Tab/Enter/空格；点击目标至少44px。手机按可用宽度自然换行；搜索和重置可直接操作，不依赖悬停。云端刷新只更新收藏数据，不清除当前筛选和焦点。
