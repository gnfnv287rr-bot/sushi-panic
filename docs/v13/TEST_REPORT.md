## 问题与修复记录

1. 旧body.play-mode样式的优先级会覆盖新布局；特别是小屏角色卡固定层跑出场景后被收藏纸页挡住。改为场景内可滚动纸层，明确本轮样式作用域；320开局及完整回归通过。
2. 前五速览移入排行榜后，旧测试的倒计时选择器匹配两项。改为核验主榜倒计时，仍保留两处真实倒计时。
3. Renderer在不同对局重用食物ID时需更新寿司插画，已按真实key变化刷新，增加回归。
4. 两次Playwright同时写默认test-results导致中间一轮trace文件被清理、出现ENOENT；改为单次串行52项完整执行。没有把该失败轮次计为通过。
5. 最后视觉复看将旧蓝色输入框改回已验收纸色，并为长菜单复用Demo右上角44px关闭图标，避免需要翻到底部才能收起菜单；6项定向复测通过。
6. 持续运动的DOM盘不适用等待位置稳定的locator.click；新增用例改为正常鼠标坐标点击，不force、不暂停传送带。原移动命中、手机触摸测试同时保留。
