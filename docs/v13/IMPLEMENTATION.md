# V1.3 Cozy Sushi Bar · 正式功能整合（已正式发布）

Owner已于本轮明确验收V1.3 Demo并锁定风格。唯一视觉基准：`design-preview/v1.3/`，提交`0e397ea`。禁止重新设计、用模拟功能替换业务或丢失玩家数据。本地开发分支`codex/v1.3-cozy-integration`；最初整合时线上为V1.2.4；2026-10-20已获Owner恢复部署授权并完成发布，见DEPLOYMENT.md。

## 整合边界

- 原Demo文件完全不变。主厨、SVG图标、圆体子集及OFL字节原样复制到`assets/cozy/`。完整已验收CSS原样复用（仅字体地址调整）。场景绘制原样复用，依赖路径改为正式模块位置。
- 新`src/renderer-cozy.js`仅接收现有引擎的真实食物/坐标/角色/状态，提供DOM餐盘和原Canvas命中兼容层。没有新增生成池、分数算法、稀有概率或存档逻辑，也不导入`demo.js`。
- `src/main.js`仅更换渲染器入口、绑定真实菜单卡及喝茶快捷操作、更新视觉状态。全部126个旧静态业务ID保留且无重复。
- 保持16个规则/数据/身份/存档/反馈模块SHA-256不变，清单见BASELINE.json。数据库、RLS、Edge Functions、认证设置、账号、存储键和数据迁移均未改动。
- 当前菜单按真实主题配置显示，包含常驻188、本期28及往期6收藏，乌龙茶另计。不能为了复制Demo的八盘假数据更改真实出盘数量。餐盘数量、速度和位置始终以引擎为准。
- 正式喝茶按钮只点击当前传送带实际存在的茶，仍经过原eatTarget、动作日志、冷却与服务端重放校验；没茶或未开局时禁用。

## 功能位置映射

| 旧功能 | V1.3位置/行为 |
| --- | --- |
| 昵称、随机角色卡、续玩未结账局 | 原入座/角色卡流程，纸质弹层；原日志与恢复逻辑 |
| 角色体质、特殊能力、忌口 | 餐台座位牌；点开看完整能力说明，真实随机角色不提供Demo的自由切换 |
| 饱腹/精神/时间/速度 | 餐台右上真实饱腹与分数；展开饱腹数字看精神、时间、速度 |
| 全量菜单/分页/主题 | 顶部菜单吊牌或餐券打开；三张真实主题卡，完整餐品分页保留；对局中禁止换菜单 |
| 图鉴222种/珍稀/NEW/搜索/分页 | 顶部图鉴或餐台下收藏纸页打开原完整图鉴，不是六卡样例 |
| 全球TOP100/本人名次/换榜/前五速览 | 排行榜吊牌；原完整榜与额外前五折叠速览，服务端日期/顺序/重试不变 |
| 游客/邮箱绑定恢复/历史档案/诊断 | 云端存档吊牌，原真实接口及安全边界 |
| 结账/自愿参榜/服务端结算/分享/失败重试 | 原业务流程与完整结算小票；结账移至收藏下方操作区 |
| 新品队列/云端确认/待同步/提醒 | 原真实发现队列与同步文案，复用纸质反馈外观；不会将本地待同步当作云端成功 |
| 音效/键盘/移动点击/休息/离开暂停 | 原规则与事件；餐盘通过同一eatTarget入口；减少动态只影响装饰，不改变服务端游戏时钟 |

原侧栏不再占据主场景。上表为功能迁移，不删除或模拟功能。保留旧样式兼容完整业务弹窗，再用已验收设计令牌统一颜色、字体和按钮；本轮没有重新制作全站美术。

## 运行与复测

```sh
npm ci
npm run build
SUSHI_DB_FILE=:memory: SUSHI_TEST_PEERS=1 node scripts/serve.mjs --port 5184
# http://127.0.0.1:5184/?casual=1 （已启动；本地独立数据库，不是生产云存档）

npm test
npm run test:e2e
npm run test:security
node scripts/verify-cozy-integration.mjs
node scripts/verify-build.mjs
```

同时保留已验收纯视觉Demo：`http://localhost:5183/design-preview/v1.3/`。两个服务都只监听本机，不能当互联网分享链接。本地内存数据在重启服务后消失；正式账号与收藏仍在原生产服务，从未用本地记录覆盖。

测试使用已有Playwright和Chrome；不增加运行依赖。只在具备独立staging配置时运行`node scripts/cozy-cloud-acceptance.mjs`，其断言锁定测试Supabase项目，真实远端Auth/Edge/PostgreSQL；不得改成生产分数夹具。

构建同时保留离线play.html和不可变资源发布目录，嵌入离线字体/主厨；以后批准发布时，图片与JS/CSS一同使用同一发布哈希，不把V1.3美术留在可混版本的地址。
