# V1.3.1 · 小店的声音

## 素材来源与使用

全部为本项目新增的原创程序合成，不引用第三方游戏音乐、录音、采样、音乐库或生成服务，无新增付费/署名依赖；没有购买或重新授权项目其他素材。

- `src/audio-score.js`：原创《A Little Table for Two》，86 BPM、16小节约44.65秒。以柔和电钢琴、指弹吉他、木琴点缀、温暖贝斯及轻刷节奏的合成音色编排。尾音环绕折回实现连续循环，峰值统一至0.52，默认音乐增益25%，无歌词。
- 同文件：7种食物声音（普通、炸物、蔬菜、软糯、炙烤、甜品、茶）、纸张展开/翻页/合拢、新发现与盖章、菜单确认。使用包络、柔化噪声和低音量泛音，不含真实咀嚼录音。
- `src/audio-manager.js`：独立轻量控制层；未新增运行库。

## 交互与性能边界

沿用已验收V1.3视觉及音效入口，只增加同风格原生设置弹窗。音乐/音效独立开关、0–60%滑杆、静音，浏览器本地保存；新音频设置首次默认全静音，旧版单一开关不自动开启新音乐。恢复偏好后仍等待真实手势创建AudioContext。

首次开启声音时才加载合成模块；音乐只离线渲染一次并缓存为立体声AudioBuffer，之后以一个loop source播放，约7.9MB PCM，不下载音频文件。16小节分批调度，循环不使用JS定时排乐。效果按类型缓存，每类去抖、最多4个并发音效和4个待准备请求，丢弃超量输入，不延迟补播。整体轻限幅。

图鉴展开时BGM降至38%，关闭恢复；只给真实上一页/下一页绑定翻页声。新品沿用真实首次发现队列；重复菜品/读云端档案不重播新品声音。静音/关音效立即终止效果并作废延迟盖章；音乐约170ms淡出。页面隐藏停止声音并暂停AudioContext，返回恢复用户偏好。加载/浏览器API失败有友好提示，游戏照常运行。

不修改Supabase、身份、排行榜、积分、菜单或收藏模块。原16个业务模块、126个原控件及已验收组件/美术哈希均保留。资源哈希同时覆盖两个音频模块，离线play.html包含合成代码。

## 验证

本地94项规则/API/数据库/音频测试通过（其中7项为新增音频单测）；14项Chrome音频/真实本地业务回归及1项完整循环观察通过。完整循环：同一native source在45.515秒后仍循环播放，观察到2720次RAF；音频长44.651秒、立体声、峰值0.520、RMS 0.0664、首尾相邻采样差0.000547。构建、资源校验、16模块/126控件/已验收美术保护及密钥扫描均通过。初期发现的入口DOM替换导致首次点击丢失已修复并复测；不计失败尝试为通过证据。正式部署后再记录公开验收结果。Chrome自动化可验证真实Web Audio图、缓存、环绕边界波形、切后台/静音及操作，不等同真人听音质量验收。真实iPhone/Android扬声器、Safari及低端手机长时帧率需要实际设备试听，本机手机尺寸模拟不代替实机。

本地：`npm ci && npm run dev`，打开终端给出的地址，点「音效：关」勾选音乐/音效。声音偏好仅在当前浏览器保存，与云端账号独立。
