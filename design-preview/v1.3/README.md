# SUSHI PANIC V1.3 · Cozy Sushi Bar 视觉Demo

**仅设计探索，等待Owner验收。** 正式游戏仍为V1.2.4；没有接入账号、API、数据库，也没有部署。

## 本地预览

在项目根目录运行：

```sh
node design-preview/v1.3/serve.mjs
```

打开 [主界面Demo](http://localhost:5183/design-preview/v1.3/) · [前后对照](http://localhost:5183/design-preview/v1.3/comparison.html)。当前预览服务已启动，只绑定127.0.0.1。地址仅在这台电脑使用，未验证其他设备/局域网访问。

服务器不初始化数据库，阻止/api和正式入口/config；CSP禁止连接外部服务。只读复用五个既有插画/目录源模块，其余代码和素材都在此目录。请使用HTTP预览，双击HTML时浏览器的ES模块安全限制可能阻止载入。

## 可以体验

- 8个餐盘慢慢回转；点击或键盘1–8品尝，原寿司插画与釉色餐盘。按P休息/继续；若打开后已自动休息，按P或点餐台下方「继续慢慢吃」。
- 默认本期示例菜单，可切换经典菜单；原四角色座位牌可切换，仅用于视觉验收。
- 模拟收藏28/222、本期4/28；第一次品尝新品增加种数，重复不重复解锁；首次焦糖三文鱼可触发小收藏卡。
- 喝茶、暂停/继续、20秒无操作自动休息、默认静音及自愿轻音效。
- 菜单纸、六张手帐卡、排行榜/存档/指南便笺，Escape可关闭。
- 模拟数据只在内存中，刷新或重新体验可重置。积分仅为显示反馈的占位计算，**不是正式规则实现**；没有把视觉Demo当完整V1.3游戏。

## 复测

已有项目依赖和本机Chrome时，保持预览服务运行：

```sh
npx playwright test -c design-preview/v1.3/tests/playwright.config.mjs
```

这只验证设计Demo；没有运行生产部署、修改规则或验证真实邮箱恢复。源码在本地分支design/v1.3-cozy-ui，正式发布分支没有合并本设计。

## 验收后再做

1. 先确认整体氛围、餐台空间和手机密度，再微调材质、盘子/食物比例及角色反应。
2. 确认后把展示组件独立接到现有真实状态和规则，逐步替换；保留旧版可回退入口。
3. 正式接入时统一元件尺寸与命中区域，沿用现有手机专注模式；测试Safari/真实触屏和低性能手机。
4. 完整图鉴、榜单、存档页面及每周主题皮肤在方向确认后逐个推广。当前没有制作全部主题或批量重做全站。
