# Cozy Sushi Bar · 视觉设计系统 v0.1

状态：独立探索稿，等待Owner验收，不能接入生产。

## 设计简报与取舍

一页就是一家店，传送带是唯一主体。屏幕从招牌/菜单牌进入餐台，食客和主厨在同一场景里，收藏册紧接餐台下沿。避免沿用“顶部hero＋仪表盘＋3张侧栏卡片”的网页模板。

布局草图：

```
[寿司小招牌]     [菜单][图鉴][排名][存档][指南][音效]
 欢迎光临，今天想吃点什么？       营业中的小提示
 ┌ 当前放题菜单 ───────────── 胃口/积分/休息 ┐
 │ 帘子        原创小主厨        一盆小绿植 │
 │         寿司 → 回转轨道 → 寿司         │
 │          留白 / 主厨轻反馈              │
 │ 座位牌（现有角色、忌口）      喝茶/休息  │
 └──────────────────────────────────────┘
 [纸页收藏册 / 已发现进度 / 本期进度 / 翻开图鉴]
```

签名元素：釉色餐盘绕着“小主厨的餐台”慢慢转，下面是一张能盖下新发现印记的收藏纸页。只在菜单牌与纸页使用轻微不规则边角，不把每个组件都做成云朵。参考色板是Owner指定方向；没有引入大面积深绿、夸张渐变或任天堂素材。

## 字体

标题：现有许可明确的ChillRoundF来源制作独立子集，修改版内部名称Sushi Cozy Round，保留OFL；仅用于短标题。正文：PingFang SC/Microsoft YaHei/system-ui；数字：系统tabular-nums，无巨型等宽计分器。层级：招牌24–27、欢迎语22–29、模块标题20–27、主要文字12–14、辅助标记9–11。准确数值可展开阅读；细小提示不作为唯一的操作或危险信号。

## 组件与图标

- 导航小菜单牌：图标24px、统一原创SVG笔画2–2.2px、端点圆润；桌面一排，手机3×2，无Emoji。
- 按钮：至少44×44px，主动作蜜桃底、深棕字；菜单/收藏为奶油底深绿字；休息天空蓝。按下位移2px，平时最多2px小投影。
- 场景：单一暖木餐台，轨道保留现有回转结构；薄雾绿轨面、淡奶油轨边，食品是强色焦点。
- 餐盘：双圈釉边、微小色点和偏心高光，低对比阴影；目标独立于装饰。
- 角色：沿用现有四种角色设定和忌口，原插画放在餐台座位牌；新主厨为本项目原猫主厨的原创延展，不使用任天堂角色。
- 收藏册：纸张/装订暗示＋一条进度，禁止四张统计卡。显示模拟总量28/222和本期4/28，继续品尝可变化。
- 弹窗：原生dialog、奶油纸面、最多一个暖色小标，按Escape关闭并恢复焦点。仅做菜单和小范围收藏卡，排行榜/存档仅展示未接入说明。
- 圆角：8/14/24；场景外壳36/32，受控地略不对称。边框1–2px，避免厚描边包围每条信息。

## 动效

| 行为 | 时长 | 表现 |
|---|---|---|
| 按钮 | 120–180ms | 下压2px、轻微回弹 |
| 换菜单 | 220ms | 菜单纸淡入，轨道原地继续 |
| 点寿司 | 280ms | 餐盘缩小淡出，主厨点头 |
| 新发现 | 240ms进入，约2.5s停留 | 小卡、原创星点、轻印章；pointer-events:none |
| 收藏增长 | 400ms | 条宽平滑增加，去重后才加种数 |
| 休息 | 220ms | 轨道停下，主厨文案/表情变化；零自动积分 |

prefers-reduced-motion时停轨，不做弹跳/位移，保留直接点击和状态反馈；切换标签页暂停，不补算后台动作。

## 响应式

桌面单一宽餐台，最大1280px，不做侧栏。手机收紧招牌，导航3×2，餐台内主厨缩小、盘子仍可点，收藏册纵向排布；横屏可自然滚动。局部表单/说明不挤压轨道。仅本机loopback访问，未验证局域网/其他设备。
