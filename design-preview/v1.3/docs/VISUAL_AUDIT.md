## 优先问题清单

1. **场景层级**：寿司应在第一层，数字与工具入口退后。现版两根大仪表条和多栏卡片占了过多重量。
2. **形状与材质**：网页圆角卡片重复，缺少菜单牌、餐盘、纸页、木台之间的区别。
3. **角色感**：可爱的原创人物和主厨已经存在，但被放进不同组件；需要在同一餐台发生互动。
4. **图标**：Emoji来源与渲染不统一，换成一致的原创SVG。
5. **字体**：新圆体方向可保留，模块正文/数据层级需更克制；不将大字和强色平均分配给所有信息。
6. **颜色**：原版清新蓝改善了明度，但很多边框、文本和功能都用同一蓝色。本次用暖棕/深绿文字，低饱和底色分工，寿司继续做色彩焦点。
7. **操作**：装饰不能盖住餐盘，说明不能替代反馈；Demo验收实测点击、重开、休息、键盘与移动尺寸。

## 无障碍与范围限制

截图能观察视觉层级、字形与目标尺寸，不能证明完整无障碍合规。Demo另测键盘、焦点返回、减少动态效果、44px按钮与无横向溢出；真实读屏、Safari、iPhone/Android真机及色觉用户尚未验证。仅观察本次本地游戏流程，不把本地榜单当云端同步验证。
