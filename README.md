# 寿司别吃撑！ · SUSHI PANIC

Game v0.2.0. Static game client with a shared online score leaderboard hosted at the game's Sites API. Choose your own player ID; the highest personal single-run score wins the 大胃王 title.

Open the GitHub Pages URL to play. API connectivity is needed for ranked runs; unavailable service is clearly marked as practice mode. A local index.html file runs as offline practice.

This repository contains only the public game client, not private project documents, database contents or credentials.
